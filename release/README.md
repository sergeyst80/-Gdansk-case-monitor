# Android-приложение

[GdanskCaseMonitor-1.2.1.apk](GdanskCaseMonitor-1.2.1.apk) — актуальная подписанная
Android-сборка с локальным переводом ML Kit и исправлениями безопасности.
Android 8.0+, все четыре архитектуры. Ключ подписи прежний;
устанавливайте поверх предыдущего release без удаления приложения.

[GdanskCaseMonitor-1.2.0.apk](GdanskCaseMonitor-1.2.0.apk) — предыдущая версия,

PDF для чтения и печати: [Русский](../docs/USER_GUIDE_RU.pdf), [English](../docs/USER_GUIDE_EN.pdf).
Контрольная сумма APK — в `SHA256SUMS`.

Проверено 2 октября 2026 года: 9 unit-тестов, 7 проверок конфигурации
безопасности, 5 проверок локализации; lint без ошибок (16 предупреждений).
Подпись APK проверена: сертификат SHA-256
`6abdebdf60173f8f25d8b2808dfc2feb0303ea839aff22cf6ca765c3ff47e976`.
